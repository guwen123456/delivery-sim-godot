# 送外卖模拟器 3D · Godot 版

手搓的 3D 全景送外卖模拟：第三人称追尾视角，在 600×420 米的临江市里抢单、取餐、送餐。

## 玩法
- 抢单（最多同时 3 单）→ 到店等出餐 → 送到顾客楼下；准时全额，超时 7 折并扣评分
- 红绿灯真实判定：闯红灯日结罚款 ¥10/次；撞汽车弹开扣分；撞行人手上的单全洒
- AI 车流会刹车避让、等红灯；行人会躲你；昼夜交替、黄昏亮灯、下雨天激励 +20%
- 一天 8:00–22:00（270 秒），目标日入 ¥260，M 静音

## 操作
W 油门 · S 刹车/倒车 · A/D 转向 · 跟着导航箭头和光柱走，左下角有小地图

## 运行
- **网页版**：https://guwen123456.github.io/delivery-sim-godot/ （打开即玩，建议桌面浏览器）
- **Windows 版**：见本仓库 Releases，下载 zip 解压后双击 DeliverySim3D.exe（exe 与 pck 需放在一起）

## 技术
Godot 4.3 / GDScript 全部程序化建城（280 栋楼、5 种程序纹理立面、70 个红绿灯路口、AI 车流与行人），
贴图由 Python PIL 程序生成，音频为代码合成音效。内置 `--qa` 自动驾驶自检（抢单→取餐→送达全闭环已通过）。
